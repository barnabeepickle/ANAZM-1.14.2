# Absolutely A Zoom Mod

## About

Absolutely A Zoom Mod is a port of [Absolutely Not A Zoom Mod](https://modrinth.com/mod/anazm) and [Logical Zoom](https://modrinth.com/mod/logical-zoom) to Minecraft 1.14.2 as neither mod supports 1.14.2.

![Mod Menu Showcase](showcase_screenshot.png)

## Dependencies

Neededs [Fabric Key Binding API for 1.14.2](https://modrinth.com/mod/fabric-key-binding-api-v1-for-1.14.2) to function.
